# JavaScript-Exam
📖 How It Works (Simple Explanation)

Tasks are stored in Local Storage as an array

Each task has:

Task name

Category

Due date

Status (Pending / Completed)

JavaScript updates the UI whenever tasks are added, edited, or deleted

Dashboard updates automatically based on tasks

🎯 Learning Outcome

By building this project, you will learn:

DOM manipulation in JavaScript

Using Local Storage

Handling forms and inputs

Writing clean beginner-level JavaScript

Creating a small real-world project
